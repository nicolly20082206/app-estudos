# Aplicativo de Organização de Estudos

## Descrição

Este projeto foi desenvolvido para ajudar estudantes a organizar seus materiais de estudo, acompanhar tarefas e melhorar o desempenho escolar.

## Nova Tela Proposta

### Nome da Tela
Painel de Estudos

### Função da Tela

Permitir que o estudante visualize seu progresso, organize tarefas e acesse rapidamente os materiais de estudo.

### Informações e Elementos da Tela

- Lista de matérias cadastradas
- Calendário de atividades
- Materiais de estudo salvos
- Barra de progresso
- Lembretes de provas e trabalhos
- Campo de pesquisa
- Botão para adicionar conteúdos

## Benefícios

- Melhor organização dos estudos
- Controle de tarefas
- Acompanhamento do progresso
- Acesso rápido aos materiais
